# 孙割长文技能库（sun-ge-skill）

> 来源《我的女友景甜》《我的男友孙哥》

## 这是什么

一个 Claude skill，专门用来写那种「很有钱但很不开心」的第一人称中文长文。

最初只分析了《我的女友景甜》的男性视角，后来读了《我的男友孙哥》，发现同一个故事从女性视角写出来，完全可以形成「对位叙事」。所以升级后的 skill 同时支持：

- 男性/给予者视角
- 女性/被观看者视角
- 双重视角的互文写法

核心就一句话：**烧钱像呼吸一样自然，悲伤像账单一样平静。**

## 怎么用

### 方式一：直接安装整个目录（推荐）

在 Claude 里用 skill 目录安装即可，具体步骤看你那边客户端怎么喂。

### 方式二：安装 `.skill` 包

把根目录下对应的 `.skill` 文件丢进去就行。如果找不到 `.skill`，可以临时打包：

```bash
cd sun-ge-skill
zip -r ../sun-ge-skill.skill .
```

## 升级要点

相比第一版，现在的 skill 增加了：

- **女性视角写作模式**：她不是被动的客体，她在计算、怀疑、选择离开。
- **对位叙事表**：同一件物件/事件，在男性视角和女性视角下分别意味着什么。
- **「看见 vs 拥有」核心冲突**：他爱的是她，还是他想象了十八年的那个影像？
- **双视角写作流程**：先写男性版，再写女性版，让两个版本互相拆穿。

## 想贡献 / 加新 skill？

规矩很简单：

1. 新建一个文件夹，名字用英文短横线连接，比如 `my-awesome-skill/`。
2. 里面放一份 `SKILL.md`。
3. `SKILL.md` 最前面要有这段 frontmatter：

```markdown
---
name: "my-awesome-skill"
description: "一句话讲清楚这 skill 干嘛用的"
---
```
4. 如果方便，顺手打个 `.skill` 包放根目录，不强制。
5. 在 README 的「现在有什么」表格里加一行。

## 协议

不设协议。看到就是缘分，随意用、随意改、随意转发。
