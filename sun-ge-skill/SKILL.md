# 疏离富有体叙事风格

## 何时使用

当你想写一个以第一人称、冷静克制、富有物质细节、情感不外露的现代中文短篇（或长篇片段）时，使用本 skill。典型题材包括：财富与孤独、不对等关系、 obsessive longing、权力的空虚、明星/名媛与普通人的情感错位。适合那种“烧钱像呼吸一样自然，悲伤像账单一样平静”的调子。

## 核心气质

1. **疏离的富有**：叙述者极其富有，但从不炫耀。钱、飞机、酒店、助理只是句子里的普通名词，像“书包”“拖鞋”一样被使用。
2. **克制的悲伤**：不哭、不喊、不解释。痛苦通过物件、账单、空房间、未完成的动作流露。
3. **精确的数字**：用数字制造荒诞感——“三十天，一百万美元”“二十六个人”“三点五微克”。数字越精确，情感越模糊。
4. **空洞的空间**：喜欢写“被包下来的空层”“空放映厅”“空飞机座位”“整层楼的胶带”。空，是权力的形状。
5. **物件承担情感**：一张照片、一排指甲锉、一卷黑胶带、一支没拆的药品，比“我爱你”更有分量。
6. **循环与重复**：关键句子、意象、动作反复出现，像卡住的黑胶唱片。结尾通常回到开头的某个空镜头。

## 文章结构

### 1. 开头：从“悬崖边”切入

不要从相识写起。从关系最紧张、最诡异或最决定性的时刻开始。用两个极不对称的事物并置，制造张力。

公式：
> 一个微小/生物性的重量，一个巨大/金钱性的重量。后者是前者被抵押的价格。

示例模板：
> 一颗卵子的重量，三点五微克。/ 五千万美元现金的重量，两点五吨。/ 她在那间海崖酒店的电话里向我要的是后者，抵押的是前者。

要点：
- 第一句要具体到几乎残酷。
- 第二句把尺度猛地拉开。
- 第三句把两个尺度绑在“她要/他给我”这个动作上。

### 2. 中段：时间跳跃，块状叙事

用 `---` 分隔不同时间切片。每一块只讲一个地点或一个事件，不要平滑过渡。让读者自己把碎片拼成关系史。

推荐的块状顺序：
1. **现在的崩塌**（她提出条件 / 她离开 / 她发现某事）
2. **遥远的起点**（我如何第一次看到她，那时候我还什么都没有）
3. **关系中的几个高光/低光时刻**（第一次见面、一次旅行、一个亲密动作、一次金钱往来）
4. **回到崩塌**（电话、沉默、决定）
5. **之后**（账单、遗物、循环的结尾）

每一块内部：
- 先写地点和动作（她去了哪里，助理做了什么）。
- 再写一句看似无关的观察（清洁工、胶带、玫瑰花、孩子的爆米花）。
- 最后落到一个小到荒谬的细节（她把头像换成一只卡通兔子；她磨我的指甲磨了一个小时）。

### 3. 对话：短，像暗号

对话遵循“她说—我说—她说—沉默”的节奏。多用“我说好”“她说不用”“我没问”“我没说”。

要点：
- 对话里不要出现超过两句的解释。
- 沉默要标出来。
- 重要的话用普通语气说，好像只是随口一提。

示例模板：
> 她说，你的指甲扎得我痛。/ 我看了一眼。/ 她说，过来。/ 她把我的手放在她腿上，一根一根磨。

### 4. 情感：用行动和账单代替表白

不要写“我很爱她”。写：
- 每换一台设备，都把那张旧图片导过去。
- 助理每月的汇总付款单里多了一项，我批得很快。
- 我把手机放在床头柜上，屏幕朝下。
- 我把手放在胸口，数了一下心跳。

金钱是爱的度量，但不是炫耀。要写得像“breathing expense”——很自然，很无奈。

### 5. 结尾：回到空镜头

结尾不要总结。让叙述者回到某个空旷的场景，重复开头的意象，或留下一个未完成的动作。

常用收尾方式：
- 一个账单/赔偿条目（酒店玻璃、飞机燃油、未拆的药品）。
- 一个被划掉的日程提醒。
- 一个他再也无法完成的小动作（磨指甲、换头像、转账）。
- 一句看似无关的观察，把全文压回沉默。

示例模板：
> 凌晨三点的城市，/ 什么都没有发生。

## 语言规范

1. **短句为主**。一个逗号一层意思，句号像呼吸停顿。
2. **不用修辞性形容词**。不写“绚烂的烟花”“悲伤的海”，只写“港口放烟花，来了一百万人”“海很大”。
3. **专有名词要具体**：酒店名、飞机型号、地名、品牌、App、机构。不要把具体酒店写成“一家豪华酒店”。
4. **数字要精确**：不要“很多钱”，要“三千万人民币”“两点五吨”“九千五百公里”。
5. **控制比喻**：比喻极少，一旦出现要出其不意且冷静，如“一座失去皇后的凡尔赛宫”“就像一个王朝在核对年号”。
6. **允许轻微的黑色幽默**：从荒诞中产生，不要笑出声的那种。

## 写作流程

1. 确定一个核心冲突/条件：她要什么？他能不能给？这个条件要同时是金钱性的和情感性的。
2. 列出三个具体物件，它们将在文中反复出现，分别代表：迷恋、亲密、失去。
3. 写开头的“双重量”句子，把核心冲突压进一个意象。
4. 用 `---` 切出 4–6 个时间块，每块写一个地点+一个事件+一个细节。
5. 在每一块里插入至少一个数字、一个助理/服务人员视角、一个未被解释的动作。
6. 写结尾时，删掉所有解释性句子，只留一个空镜头或一个账单条目。
7. 通读一遍，把所有“我觉得”“我感到很”“她很美”之类的主观判断，改写成动作或物件。

## 检查清单

- [ ] 开头是否有“微小重量 vs 巨大重量”的并置？
- [ ] 是否用了至少三个精确数字？
- [ ] 是否有至少一个“空”的空间或场景？
- [ ] 对话是否短于三行，且包含沉默或“我说好”？
- [ ] 是否有一个小物件承载了主要情感？
- [ ] 结尾是否回到某个开头意象，或留下未完成的动作？
- [ ] 是否删除了所有直接抒情句？
- [ ] 是否有一句来自助理/服务人员的视角，让权力显得日常？

## 示范片段

> 她的头发重量，八十二克。/ 一艘七十六米游艇的停泊费，一夜七千欧元。/ 她在码头边向我要的是后者，抵押的是前者。
>
> 她去那里是为了剪头发。发型师从米兰飞来，工具箱里有一把十九世纪的银剪。这是她主动提的。到了码头，她说没有七千欧，不剪。
>
> 码头灯火通明，像一条浮在海上的商业街。我把整条船包下来，三十天，为了她的安静。她住了五天就走了。
>
> 剩下的二十五天，船员每天照常升旗、擦甲板、在甲板上摆好六套餐具。是我的船长讲的，他夜里巡逻，看见服务生把一张没人坐过的椅子扶正，退后一步看了看，又扶了一次。
>
> 船长问，没人住，为什么还要摆。
>
> 服务生说，登记上写着有人。
>
> 一座失去女王的邮轮。
