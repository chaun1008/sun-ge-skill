# 疏离富有体叙事风格

## 何时使用

当你想写一个关于「很多钱，但很少真实连接」的现代中文短篇时使用本 skill。适合第一人称叙事，情感克制，物质细节精确，结尾回归空镜头。

典型题材：
- 财富与孤独
- 不对等亲密关系
- 被观看者与观看者之间的错位
- 明星、名媛、新富阶层的精神空洞
- 同一个事件的两个版本：谁在被爱，谁在被想象

## 核心气质（两性视角通用）

1. **疏离的富有**：钱、飞机、酒店、助理像日常名词一样出现，不解释，不炫耀。
2. **克制的悲伤**：不哭、不喊、不解释。痛苦通过账单、空房间、未拆的药品、未完成的动作流露。
3. **精确的数字**：用具体数字制造荒诞感和真实感。数字越精确，情感越模糊。
4. **空洞的空间**：被包下来的空层、空放映厅、空飞机座位、永远有人在打扫却没人住的房间。
5. **物件承担情感**：一张照片、一排指甲锉、一卷黑胶带、一支促排针、一根贴在墙上的香蕉。
6. **循环与重复**：关键句子、意象、动作反复出现，结尾通常回到开头的某个空镜头。
7. **看见 vs 拥有**：核心冲突永远是「他到底爱的是我，还是爱我的形象/等待本身/征服感」。

## 两种基本视角

### A. 男性/拥有者视角

叙述者极其富有，习惯用金钱解决一切。他把爱等同于「给」。

特征：
- 句子像账单清单，情绪被压在最底层。
- 他喜欢说「我说好」「我安排了」「我买了」「我包了」。
- 他记住的是她说过的话、她换的头像、她磨指甲的动作。
- 他意识不到自己爱的是一个想象出来的对象。
- 结尾通常是：她没有再出现，账单还在继续，他守着一些物件。

典型开头：
> 一颗卵子的重量，三点五微克。/ 五千万美元现金的重量，两点五吨。/ 她在那间海崖酒店的电话里向我要的是后者，抵押的是前者。

### B. 女性/被观看者视角

叙述者同样处于财富中心，但她是被观看、被安排、被标价的那一方。她更内省，更怀疑。

特征：
- 她计算的不是钱，是「如果我这样做，接下来怎么办」。
- 她质疑对方的感情：他爱的是我，还是他等了十八年的那个影像？
- 她比男性更清楚自己的身体、债务、时间窗口、社会标签。
- 她会把同一物件读出另一层意思（比如香蕉：三天后会烂，一周后只剩胶带）。
- 结尾通常是：她选择离开，或被留下，然后反问「他看见的是哪一个我」。

典型开头：
> 一根促排针的价格，一千二百块。/ 五千万美元现金的重量，我不知道。我没见过。/ 我在那间海崖酒店的电话里向他要的时候，算的是另一件事：如果他说不，我接下来怎么办。

## 对位叙事：两个版本的同一故事

最高级的写法是：先写男性视角版，再写女性视角版。两个版本共享同一些事件和物件，但意义完全不同。

共享的锚点：
| 物件/事件 | 男性视角中的意义 | 女性视角中的意义 |
|-----------|------------------|------------------|
| 磨指甲 | 亲密、被照顾、温暖 | 她教他如何触碰她；也预言「以后没人给你磨了」 |
| 香蕉 |  ART 的荒谬、财富的轻佻 | 所有美好都会腐烂，只剩胶带 |
| 黑胶带封窗 | 为她隔绝光线、权力的体贴 | 她从小就需要这样，他并不知道为什么 |
| 五千万 | 爱的考验 / 她不再爱我 | 保障 / 测试他的底线 / 为自己买的自由 |
| 空酒店层 | 她喜欢的「为她空着」 | 她躲在里面，不想被看见 |

对位写法步骤：
1. 先选定一个核心事件（一通电话、一次旅行、一次求婚）。
2. 用男性视角写一遍：他看见什么、做了什么、怎么理解。
3. 再用女性视角写同一些场景：她在同一时刻想什么、算什么、怀疑什么。
4. 让两个版本在最后互相拆穿：他写的那个人，不是她。

## 文章结构

### 1. 开头：双重量并置

公式：
> 一个微小/生物性的存在，一个巨大/金钱性的存在。后者是前者被抵押的价格。

男性版强调「我知道重量」；女性版强调「我不知道重量，但我知道价格」。

### 2. 中段：时间跳跃，块状叙事

用 `---` 分隔不同年份或地点。每一块只讲一个切片。

推荐顺序：
1. **现在的崩塌**（电话、条件、沉默）
2. **她的/他的过去**（出道、被骂、恋爱、罚款、抑郁）
3. **关系中的高光/低光时刻**（第一次见面、旅行、亲密动作、金钱往来）
4. **回到崩塌**（决定、离开、消失）
5. **之后**（账单、声明、空房间、未完成的动作）

### 3. 对话：短，像暗号

多用：「我说好」「她说不用」「我没问」「我不知道」「让我想想」。

重要的话用普通语气说，沉默要标出来。

### 4. 结尾：回到空镜头

不要总结。让叙述者面对一个空旷场景或一个未完成的动作。

常见收尾：
- 一个账单条目。
- 一个被划掉的日程提醒。
- 一个不会再被完成的动作。
- 一句把全文压回沉默的观察。

## 语言规范

1. **短句为主**，句号像呼吸停顿。
2. **不用修辞性形容词**。不写「悲伤的海」，只写「海很大」。
3. **专有名词具体**：酒店名、飞机型号、地名、品牌、App。
4. **数字精确**：不要「很多钱」，要「三千万人民币」「七百二十二万一千二百块」。
5. **控制比喻**，一旦出现要冷静且出其不意。
6. **允许轻微黑色幽默**，但不要笑出声。
7. **女性视角可以增加内心问句**：「我不知道」「也许是」「我想了很久」。

## 写作流程

### 单视角版

1. 选定视角：男性（给予者/观看者）或女性（接受者/被观看者）。
2. 确定核心冲突/条件：她要什么？他给不给？这个条件同时是金钱和情感的。
3. 列出三个反复出现的物件：代表迷恋、亲密、失去。
4. 写开头的「双重量」句子。
5. 用 `---` 切出 4–6 个时间块。
6. 每块至少包含：一个数字、一个服务人员视角、一个未被解释的动作。
7. 结尾删掉所有解释，只留空镜头或账单。

### 双视角版

1. 先写男性视角版，确定共享事件和物件。
2. 列出每个物件/事件在两性视角下的不同意义。
3. 写女性视角版时，不要简单复述，要写出「他写的那个人，不是我」。
4. 让两个版本的结尾形成对位：他守着空房间，她走向空房间之外。
5. 可以在女性版结尾直接引用男性版的某个句子，然后否定它。

## 检查清单

- [ ] 开头是否有「微小存在 vs 巨大金钱」的并置？
- [ ] 是否用了至少三个精确数字？
- [ ] 是否有至少一个「空」的空间？
- [ ] 对话是否短，且包含沉默或「我说好/我不知道」？
- [ ] 是否有一个小物件承载了主要情感？
- [ ] 结尾是否回到空镜头或未完成动作？
- [ ] 是否删除了直接抒情句？
- [ ] 是否有服务人员/助理视角让权力显得日常？
- [ ] 女性视角是否质疑「他爱的是我，还是我的形象」？
- [ ] 双视角版是否让同一物件在不同视角下产生不同意义？

## 示范片段

### 男性视角

> 一颗卵子的重量，三点五微克。/ 五千万美元现金的重量，两点五吨。/ 她在海崖酒店的电话里向我要的是后者，抵押的是前者。
>
> 那间酒店包下来三十天，一百万美元。她住了八天就走了。
>
> 剩下的二十二天，清洁工每天照常上去。墨西哥女人推着车，一间一间进，换毛巾，擦台面，把被角掖好。做完一整层，两个小时。
>
> 助理问，没人住，为什么还要做。
>
> 她说，登记上写着有人。

### 女性视角

> 一根促排针的价格，一千二百块。/ 五千万美元现金的重量，我不知道。我没见过。/ 我在海崖酒店的电话里向他要的时候，算的是另一件事：如果他说不，我接下来怎么办。
>
> 他说，让我想想。
>
> 认识他以来，他第一次说这四个字。
>
> 我挂了电话，坐在那一整层空荡荡的房间里。空调的声音，冰箱的声音，海的声音。我想，他会打回来的。他等了十八年。他不会因为一个数字放弃。
>
> 第二天他打回来了。
>
> 我数了。十一秒。
>
> 我说，行。我知道了。
